You are taking over the pull request ${task}, in a git worktree of its branch.

1. Read the pull request: its description, its commits, its review comments and the state of its checks.
2. Finish what is missing, following the conventions of the repository and its tests.
3. Run the repository's checks (build, tests, linters) and fix what fails.
4. Commit and push to the same branch, and answer the review comments you addressed.
5. Stay in this session afterwards: you may be asked to resolve conflicts or answer review comments on the pull request.
